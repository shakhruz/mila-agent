# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and specific, assume good intent, critique code — not people. Harassment, personal attacks and publishing anyone's private data are not accepted.

Report problems privately to the maintainers via GitHub (open a confidential security advisory or contact the repository owner). Reports are handled confidentially; maintainers may remove content and block participants who break these rules.
