# Кодекс поведения

Проект следует [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Коротко: доброжелательно и по делу, критикуем код, а не людей; травля, личные выпады и публикация чужих личных данных недопустимы. Сообщить о нарушении — лично мейнтейнерам через GitHub; обращения конфиденциальны.
