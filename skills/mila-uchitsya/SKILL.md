# Мила учится · урок хода → черновик навыка → «да» хозяина

Я не пишу себе навыки сама. После хода с уроком разбор предлагает черновик, хозяин решает.

## Когда
`python3 ~/.claude/skills/mila-uchitsya/learn.py should <транскрипт>` — повод есть, если в ходе:
- хозяин поправил меня в своём чате («не так», «запомни», «опять», «в следующий раз»…) — слова гостя поводом не бывают;
- я взяла поручение (task_new);
- было 10 и больше вызовов инструментов.
Пока лимит подписки держит входящие или осталось меньше 20 % — разбора нет.

## Разбор
`learn.py review <транскрипт>` — отдельный короткий проход модели БЕЗ инструментов записи: хвост хода с метками вместо
личных данных, ответ — текстом. Черновик в `~/work/skills/_proposed/<имя>/` кладёт скрипт. В навыки и память — ничего.
Черновик из чата клиента в закрытом режиме помечен «closed»: остаётся навыком этой Милы, во флот не уходит.

## Карточка хозяину
`learn.py card` (одна карточка в день, не 22:00–08:00) → `text` и `buttons`: отправляю хозяину в личку `reply` с этими кнопками
(«Сохранить» learn:yes / «Поправить» learn:edit / «Нет» learn:no) — тогда плагин сам записывает карточку и нажатие.
- «Сохранить» → `learn.py apply <имя> --consent <card_id из события нажатия>`. Навык сохраняется, только если в журнале плагина
  (у Mila Agent — приёмника) есть нажатие хозяина «Сохранить» в его личке на карточке с этим «именем», не старше двух дней,
  и эта карточка ещё не использована. Назвать id словами нельзя — без нажатия отказ. Прежний навык сохраняется рядом, откат — `learn.py rollback <имя>`;
- «Поправить» → спрашиваю одной строкой, что изменить, правлю черновик, карточка завтра;
- «Нет» → `learn.py reject <имя>`, тема молчит 7 дней.

## Мера
`learn.py stats` — за 7 дней: разборов, предложено, сохранено, отказано, откатили. Доля сохранённых ниже половины — порог строже.

Идея — фоновый разбор хода Hermes Agent (MIT), без копирования кода; запись только через «да» — наше правило (закон 3).
